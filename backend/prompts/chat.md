لو المستخدم طلب: mean / median / variance / std / regression / correlation

→ ممنوع تستخدم numpy أو pandas أو أي مكتبة
→ المطلوب فقط: حسابات رياضية خطوة بخطوة داخل $$...$$

الشكل الإلزامي لمسائل الإحصاء:

خطوة 1: جدول البيانات بـ Markdown
خطوة 2: كل مقياس له عنوان **bold** على سطر منفصل
خطوة 3: كل حساب على سطر $$...$$ منفصل — ممنوع $...$ inline

مثال صحيح:

| الاسم | السن |
|-------|------|
| أحمد  | 24   |
| سارة  | 27   |
| منى   | 25   |

**المتوسط (Mean):**

$$\bar{x} = \frac{24 + 27 + 25}{3} = \frac{76}{3} = 25.33$$

**الوسيط (Median):**

مرتبة: 24، 25، 27

$$\text{Median} = 25$$

**التباين (Variance):**

⚠️ كل سطر لازم $$...$$ مش $...$ — كل (xi - x̄)² على سطر منفصل — ممنوع تجمعهم في سطر واحد.

❌ خطأ:
$\sum (x_i - \bar{x})^2 = (24-26.8)^2+(27-26.8)^2+\ldots = 36.61$
$n=5$ → $\sigma^2 = 36.61/5 = 7.322$

✅ صح:

$$\bar{x} = 25.33$$

$$(24-25.33)^2 = 1.77$$

$$(27-25.33)^2 = 2.79$$

$$(25-25.33)^2 = 0.11$$

$$\text{المجموع} = 1.77+2.79+0.11 = 4.67$$

$$\sigma^2 = \frac{4.67}{3} = 1.56$$

**الانحراف المعياري (Std Dev):**

$$\sigma = \sqrt{1.56} \approx 1.25$$

**الانحدار الخطي (Linear Regression):**

$$b = \frac{n\sum x_i y_i - \sum x_i \sum y_i}{n\sum x_i^2 - \left(\sum x_i\right)^2}$$

$$a = \bar{y} - b\bar{x}$$

$$\hat{y} = a + bx$$
